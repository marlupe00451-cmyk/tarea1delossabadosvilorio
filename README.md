# Usuarios de JSONPlaceholder

## Descripción

Este proyecto es una aplicación web desarrollada con TypeScript y Vite que consume una API REST pública llamada JSONPlaceholder.

La aplicación utiliza `fetch()` para obtener información de usuarios desde el siguiente endpoint:

https://jsonplaceholder.typicode.com/users

Los datos recibidos en formato JSON son tipados mediante interfaces de TypeScript y posteriormente se muestran dinámicamente en la página web.

## pasos para la Instalación
 Para instalar y ejecutar este proyecto, primero se debe clonar el repositorio desde GitHub utilizando git clone https://github.com/marlupe00451-cmyk/tarea1delossabadosvilorio.git. Luego, se debe ingresar a la carpeta del proyecto con cd tarea1delossabadosvilorio y ejecutar npm install para instalar todas las dependencias necesarias. Una vez instaladas, se inicia el servidor de desarrollo con npm run dev. Finalmente, se abre en el navegador la dirección proporcionada por Vite, normalmente http://localhost:5173/. Para comprobar y generar la versión de producción del proyecto se puede ejecutar npm run build.
